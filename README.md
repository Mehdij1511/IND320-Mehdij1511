# IND320 Portfolio App

Streamlit application for IND320 data analyses.

## Structure

- `main.py`: integrated application navigation
- `app_pages/`: Streamlit pages, organized by Reservoirs, Weather, Electricity flows, and Data sources
- `utils/`: data access and analysis modules
- `scripts/`: Cassandra and MongoDB loading/processing scripts
- `data/`: local shapefiles and ERA5 cache
- `Project Notebooks/`: project notebooks
